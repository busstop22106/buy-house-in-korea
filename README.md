# buy-house-in-korea

한국에서 내 집 마련하는 인생 시뮬레이션 웹 인디게임.

- 1980~2000년생, 수도권(서울·경기·인천)에서 사회초년생으로 출발
- 1턴 = 1년, 19세 수능부터 60세 은퇴까지 10개 생애 이벤트
- 선택지 결과는 통계청·한국은행·한국부동산원 등 실제 수치 기반, 출처 표기
- 지도에서 아파트를 골라 매수 / 청약 / 전세, 은퇴 시 총자산 랭크보드
- 데이터는 공공 API 우선, 연도·단지·지역 테이블 분리로 추후 연대·지역 확장 가능
